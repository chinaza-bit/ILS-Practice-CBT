PRACTICE CBT WEBSITE — SAMISTINTECH

This project is a student practice CBT portal, not an official examination.

COURSES
- ILS 212 — 350 practice questions in 5 batches of 70.
- GST 212 — 100 practice questions in 5 batches of 20, based on the provided GST 212 question set.

The home page (index.html) lets students choose a course. Each course has its own dedicated page.

GST 212 SOURCE
The GST 212 practice questions were extracted from the user-provided "BENJAMIN. GST 212 PQ-A Exam.pdf". The file contains 100 philosophy questions with four options and marked answers. No outside corrections were applied to the source answers.

FEATURES
- Course selection at the beginning
- Dedicated page for each course
- Student name
- Batch selection
- Question-count selection
- One-minute-per-question timer
- Question navigator
- Answer/flag tracking
- Results and review
- Random question order
- Balanced random answer-position placement
- 15-second animated loading screen
- Smooth transitions
- Responsive mobile/desktop layout
- Light/dark theme
