Question coverage
The question bank is based on the ILS 212 course topics used to build this practice question bank. Additional CBT-style questions were generated from the course material so that the question bank covers the major topics across Modules 1–5.

Topics covered include:
- Module 1: information, types/categories of information, information sources, primary/secondary/tertiary sources, library resources, information literacy, IL functions, importance, IL skills, evaluation criteria and access to IL.
- Module 2: academic, school, public, national, special, private and virtual/digital libraries; library functions; library user education; user-education objectives and methods; library resources and services; reference services.
- Module 3: search strategy, keyword/subject/phrase searching, truncation, wildcard searching, Boolean operators, quotation marks, parentheses, citation searching, filters, study skills, time management, active reading, note-taking, test preparation, memory techniques, goal setting, active learning, procrastination, motivation and test anxiety.
- Module 4: library catalogue, card catalogue, OPAC, call numbers, bibliography, indexing, types of indexes, abstracting, databases, search engines, social media and Internet access/uses.
- Module 5: ethical use of information, plagiarism and its types/consequences, referencing and styles, intellectual property, patents, trademarks, copyright, fair use, AI tools, AI ethics, misinformation/deepfakes, privacy, bias/fairness and academic integrity.
